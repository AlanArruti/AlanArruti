### 🎥 Sentinel

Plataforma de videoanálisis con IA para múltiples clientes y cámaras (repo privado).

- Modelos de detección **YOLOv8** propios, entrenados y evaluados contra conteos reales.
- Detección y seguimiento de objetos en tiempo real en **C++**, con aceleración por GPU y varias cámaras en vivo.
- Servicios desacoplados por **Kafka** (C++ → Python → Java) con reglas configurables: sumar un cliente no requiere código.
- Backend en **Spring Boot + PostgreSQL** con registro de conteos auditable.
- Dashboard en **React** con video en vivo, reportes PDF / Excel y alertas por Telegram.
